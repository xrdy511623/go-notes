### How to use skills
- Trigger rules: If the user names a skill (with `$SkillName` or plain text) OR the task clearly matches a skill's description, you must use that skill for that turn.
- For debugging tasks, `systematic-debugging` is mandatory before proposing fixes.
- If multiple skills apply, choose the minimal set that covers the task.
- If a named skill path cannot be read, state it briefly and continue with best fallback.
