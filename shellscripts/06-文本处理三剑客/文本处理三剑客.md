## 1 正则表达式基础

**正则表达式**（Regular Expression, regex）是文本处理三剑客的公共基础。grep、sed、awk 都依赖它来定位和匹配文本，掌握正则是高效使用这些工具的前提。

### 1.1 基本正则表达式（BRE）

**BRE**（Basic Regular Expression）是 POSIX 定义的基础正则语法，`grep` 和 `sed` 默认使用 BRE。

| 元字符 | 含义 | 示例 |
|--------|------|------|
| `.` | 匹配任意单个字符 | `a.c` → abc, aXc |
| `*` | 前一个字符重复 0 次或多次 | `ab*c` → ac, abc, abbc |
| `^` | 匹配行首 | `^#` → 以 # 开头的行 |
| `$` | 匹配行尾 | `\.conf$` → 以 .conf 结尾的行 |
| `[abc]` | 字符集合，匹配其中任意一个 | `[aeiou]` → 匹配元音 |
| `[^abc]` | 否定字符集，不匹配其中任何一个 | `[^0-9]` → 非数字 |
| `\(\)` | 分组捕获 | `\(ab\)*` → 匹配 ab 的重复 |
| `\{\}` | 重复次数 | `a\{2,4\}` → aa, aaa, aaaa |

```bash
# 匹配以数字开头的行
grep '^[0-9]' data.txt

# 匹配恰好 3 个字母 a
grep 'a\{3\}' data.txt
```

### 1.2 扩展正则表达式（ERE）

**ERE**（Extended Regular Expression）在 BRE 基础上增加了元字符，且不需要反斜杠转义。`grep -E`（或 `egrep`）和 `sed -E` 使用 ERE。

| 元字符 | 含义 | 示例 |
|--------|------|------|
| `+` | 前一个字符重复 1 次或多次 | `ab+c` → abc, abbc（不匹配 ac） |
| `?` | 前一个字符重复 0 或 1 次 | `colou?r` → color, colour |
| `\|` | 或运算 | `cat\|dog` → cat 或 dog |
| `()` | 分组（无需转义） | `(ab)+` → ab, abab |
| `{}` | 重复次数（无需转义） | `a{2,4}` → aa, aaa, aaaa |

```bash
# ERE：匹配 IP 地址的粗略模式
grep -E '([0-9]{1,3}\.){3}[0-9]{1,3}' access.log
```

### 1.3 BRE 与 ERE 对照表

| 功能 | BRE 写法 | ERE 写法 |
|------|----------|----------|
| 分组 | `\(abc\)` | `(abc)` |
| 重复 N 次 | `a\{3\}` | `a{3}` |
| 一次或多次 | 不支持（用 `aa*` 替代） | `a+` |
| 零次或一次 | 不支持 | `a?` |
| 或 | 不支持 | `a\|b` |

> **提示**：awk 原生使用 ERE 语法，不需要额外选项。

### 1.4 POSIX 字符类

在 `[]` 内使用 `[:class:]` 可以匹配特定字符类别，比硬编码范围更具可移植性。

| 字符类 | 等价于 | 含义 |
|--------|--------|------|
| `[:alpha:]` | `[a-zA-Z]` | 字母 |
| `[:digit:]` | `[0-9]` | 数字 |
| `[:alnum:]` | `[a-zA-Z0-9]` | 字母和数字 |
| `[:space:]` | `[ \t\n\r\f\v]` | 空白字符 |
| `[:upper:]` | `[A-Z]` | 大写字母 |
| `[:lower:]` | `[a-z]` | 小写字母 |
| `[:punct:]` | | 标点符号 |
| `[:blank:]` | `[ \t]` | 空格和 Tab |

```bash
# 匹配包含数字的行
grep '[[:digit:]]' data.txt

# 匹配纯字母组成的单词
grep -w '[[:alpha:]]\+' data.txt
```

> ⚠️ **注意**：POSIX 字符类必须放在 `[]` 内部，写成 `[[:digit:]]` 而不是 `[:digit:]`，后者会被解析为普通字符集。

### 1.5 贪婪匹配

BRE 和 ERE 中的 `*`、`+` 等量词都是**贪婪**（greedy）的——尽可能匹配最长的字符串。

```bash
# 贪婪匹配示例：
echo '<b>bold</b> and <i>italic</i>' | grep -oE '<.*>'
# 输出：<b>bold</b> and <i>italic</i>  （匹配了整行）

# 要匹配最短内容，使用排除法
echo '<b>bold</b> and <i>italic</i>' | grep -oE '<[^>]*>'
# 输出：<b>  </b>  <i>  </i>（分别匹配每个标签）
```

> **提示**：标准 BRE/ERE 不支持非贪婪量词 `*?`、`+?`。如果需要，可使用 `grep -P`（Perl 正则）或在模式中使用 `[^x]*` 排除法。

## 2 grep 家族

**grep**（Global Regular Expression Print）是最常用的文本搜索工具，从输入中筛选匹配正则的行并输出。

### 2.1 核心选项

| 选项 | 含义 | 示例 |
|------|------|------|
| `-i` | 忽略大小写 | `grep -i "error" log` |
| `-v` | 反转匹配（输出不匹配的行） | `grep -v "^#" config` |
| `-n` | 显示行号 | `grep -n "TODO" main.go` |
| `-c` | 只输出匹配行数 | `grep -c "ERROR" app.log` |
| `-l` | 只输出包含匹配的文件名 | `grep -rl "fmt.Println" .` |
| `-L` | 只输出不包含匹配的文件名 | `grep -rL "Copyright" src/` |
| `-r` / `-R` | 递归搜索目录 | `grep -r "panic" ./` |
| `-w` | 全词匹配 | `grep -w "int" code.go` |
| `-x` | 全行匹配 | `grep -x "OK" status.txt` |
| `-o` | 只输出匹配的部分 | `grep -oE '[0-9]+' data` |
| `-A N` | 显示匹配行后 N 行 | `grep -A 3 "Error" log` |
| `-B N` | 显示匹配行前 N 行 | `grep -B 2 "Error" log` |
| `-C N` | 显示匹配行前后各 N 行 | `grep -C 5 "panic" log` |
| `-E` | 使用扩展正则（ERE） | `grep -E "err\|warn"` |
| `-F` | 固定字符串匹配（不解析正则） | `grep -F "a.b" file` |
| `-P` | 使用 Perl 正则（GNU 扩展） | `grep -P "\d{4}" file` |
| `--color` | 高亮匹配部分 | `grep --color=auto "key"` |
| `--include` | 限制搜索的文件类型 | `grep -r --include="*.go"` |
| `--exclude-dir` | 排除目录 | `grep -r --exclude-dir=vendor` |

### 2.2 实战示例

**搜索日志中的错误：**

```bash
# 显示 ERROR 行及行号
grep -n "ERROR" app.log

# 忽略大小写，同时显示前 1 行和后 3 行上下文
grep -inA 3 -B 1 "error" app.log
```

**递归搜索项目代码：**

```bash
# 在 Go 项目中搜索 TODO，排除 vendor 目录
grep -rn "TODO" --include="*.go" --exclude-dir=vendor .

# 搜索包含 "func Test" 的测试文件
grep -rn "func Test" --include="*_test.go" .
```

**统计匹配行数：**

```bash
# 统计各级别日志的数量
grep -c "ERROR" app.log
grep -c "WARN"  app.log
grep -c "INFO"  app.log
```

**上下文显示：**

```bash
# 搜索 panic 并显示上下文，方便定位堆栈
grep -n -A 10 "panic" app.log
```

**多模式匹配：**

```bash
# 同时搜索多个关键词
grep -E "error|warn|fatal" app.log

# 等价写法：多个 -e 选项
grep -e "error" -e "warn" -e "fatal" app.log
```

**提取特定内容：**

```bash
# 从 Nginx 日志中提取所有 IP 地址
grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' access.log

# 从 HTML 中提取所有 URL
grep -oP 'https?://[^\s"<>]+' index.html
```

### 2.3 grep vs egrep vs fgrep

| 命令 | 等价于 | 正则类型 | 适用场景 |
|------|--------|----------|----------|
| `grep` | — | BRE | 通用搜索 |
| `egrep` | `grep -E` | ERE | 需要 `+`, `?`, `\|` 等扩展语法 |
| `fgrep` | `grep -F` | 不解析正则 | 搜索含有 `.` `*` 等字面字符的字符串 |

> **提示**：`egrep` 和 `fgrep` 已被标记为废弃，推荐使用 `grep -E` 和 `grep -F`。

## 3 sed 流编辑器

**sed**（Stream Editor）是一个非交互式的流编辑器，逐行处理文本，适合自动化的查找、替换、删除和插入操作。

### 3.1 工作原理

sed 对输入流逐行处理，每一行经过以下步骤：

```
 ┌──────────────────────────────────────┐
 │            输入流（文件/管道）          │
 └───────────────┬──────────────────────┘
                 │ 读取一行
                 ▼
         ┌───────────────┐
         │   模式空间      │ ← 当前行的工作缓冲区
         │ (Pattern Space)│
         └───────┬───────┘
                 │ 依次执行 sed 命令
                 ▼
         ┌───────────────┐
         │  执行命令序列    │  s/old/new/  d  p  a  ...
         └───────┬───────┘
                 │
                 ▼
         ┌───────────────┐
         │   输出结果      │ → 标准输出（除非 -n）
         └───────────────┘
                 │
                 ▼
            处理下一行（循环）
```

核心概念：**模式空间**（Pattern Space）是 sed 处理每一行的临时缓冲区。还有一个**保持空间**（Hold Space）用于跨行操作，高级场景下使用。

### 3.2 地址定位

sed 命令可以用**地址**限定只作用于特定行。

| 地址形式 | 含义 | 示例 |
|----------|------|------|
| `N` | 第 N 行 | `3d` → 删除第 3 行 |
| `$` | 最后一行 | `$p` → 打印最后一行 |
| `N,M` | 第 N 到 M 行 | `2,5d` → 删除第 2-5 行 |
| `N~step` | 从第 N 行开始每隔 step 行 | `1~2p` → 打印奇数行 |
| `/pattern/` | 匹配正则的行 | `/^#/d` → 删除注释行 |
| `/start/,/end/` | 从 start 匹配到 end 匹配的范围 | `/BEGIN/,/END/p` |
| `N,/pattern/` | 从第 N 行到匹配 pattern 的行 | `1,/^$/d` → 删第 1 行到首个空行 |
| `addr!` | 地址取反 | `1!d` → 删除除第 1 行外的所有行 |

```bash
# 打印第 5 到第 10 行
sed -n '5,10p' file.txt

# 打印匹配 START 到 END 之间的内容
sed -n '/START/,/END/p' config.txt

# 删除除前 3 行外的所有行（保留前 3 行）
sed '1,3!d' file.txt

# 每隔一行打印（打印奇数行）
sed -n '1~2p' file.txt
```

### 3.3 核心编辑命令

| 命令 | 含义 | 示例 |
|------|------|------|
| `p` | 打印当前行 | `sed -n '3p' file` |
| `d` | 删除当前行 | `sed '5d' file` |
| `s/old/new/` | 替换第一个匹配 | `sed 's/foo/bar/' file` |
| `s/old/new/g` | 替换所有匹配 | `sed 's/foo/bar/g' file` |
| `a\text` | 在匹配行后追加文本 | `sed '/mark/a\new line' file` |
| `i\text` | 在匹配行前插入文本 | `sed '1i\header' file` |
| `c\text` | 替换匹配行的整行 | `sed '/old/c\new line' file` |
| `y/abc/ABC/` | 字符转换（类似 `tr`） | `sed 'y/abc/ABC/' file` |
| `=` | 打印行号 | `sed -n '/ERROR/=' log` |
| `q` | 读到匹配行后退出 | `sed '10q' file` → 打印前 10 行 |

**替换命令 `s` 详解：**

`s/pattern/replacement/flags` 是 sed 最常用的命令。

| 标志 | 含义 |
|------|------|
| `g` | 全局替换（每行中所有匹配） |
| `i` / `I` | 忽略大小写（GNU sed） |
| `N` | 只替换第 N 个匹配 |
| `p` | 替换成功时打印该行 |
| `w file` | 替换成功的行写入文件 |

**反向引用：**

```bash
# & 代表整个匹配内容
echo "hello world" | sed 's/[a-z]*/(&)/g'
# 输出：(hello) (world)

# \1, \2 引用分组捕获
echo "2026-03-09" | sed -E 's/([0-9]{4})-([0-9]{2})-([0-9]{2})/\3\/\2\/\1/'
# 输出：09/03/2026
```

**分隔符替换：**

当模式或替换内容包含 `/` 时，换用其他分隔符更清晰。

```bash
# 用 # 作分隔符处理路径
sed 's#/usr/local/bin#/opt/bin#g' config.txt

# 用 | 作分隔符
sed 's|http://old.example.com|https://new.example.com|g' urls.txt
```

### 3.4 常用选项

| 选项 | 含义 | 示例 |
|------|------|------|
| `-n` | 安静模式，不自动打印，配合 `p` 使用 | `sed -n '5p' file` |
| `-i` | 原地修改文件 | `sed -i 's/old/new/g' file` |
| `-i.bak` | 原地修改并创建备份 | `sed -i.bak 's/old/new/g' file` |
| `-e` | 执行多条 sed 命令 | `sed -e 's/a/A/' -e 's/b/B/' file` |
| `-f script` | 从文件读取 sed 命令 | `sed -f cmds.sed file` |
| `-E` / `-r` | 使用扩展正则（ERE） | `sed -E 's/(foo)+/bar/' file` |

> ⚠️ **注意**：macOS 的 `sed -i` 必须跟一个备份后缀参数（可以用 `''` 表示不要备份：`sed -i '' 's/old/new/' file`），而 GNU sed 可以直接 `sed -i 's/old/new/' file`。

### 3.5 实战示例

**删除空行：**

```bash
sed '/^$/d' file.txt
# 删除只含空白字符的行
sed '/^[[:space:]]*$/d' file.txt
```

**注释 / 取消注释配置项：**

```bash
# 将 PermitRootLogin 行注释掉
sed -i 's/^PermitRootLogin/#&/' /etc/ssh/sshd_config

# 取消注释
sed -i 's/^#\(PermitRootLogin\)/\1/' /etc/ssh/sshd_config
```

**批量修改配置文件：**

```bash
# 批量替换所有 .conf 文件中的主机名
sed -i 's/old-host\.example\.com/new-host.example.com/g' /etc/app/*.conf
```

**提取两个标记之间的内容：**

```bash
# 提取 <config> 和 </config> 之间的行
sed -n '/<config>/,/<\/config>/p' app.xml
```

**在指定行前后插入内容：**

```bash
# 在第 3 行后追加一行
sed '3a\# This is a new comment' config.txt

# 在匹配行前插入
sed '/\[database\]/i\# Database configuration' config.ini
```

**sed 中使用 Shell 变量：**

```bash
HOST="db.example.com"
PORT=5432

# 双引号允许变量展开
sed "s/DB_HOST=.*/DB_HOST=${HOST}/" .env
sed "s/DB_PORT=.*/DB_PORT=${PORT}/" .env

# 变量含有 / 时，用其他分隔符或转义
DIR="/usr/local/share"
sed "s#INSTALL_DIR=.*#INSTALL_DIR=${DIR}#" config.mk
```

## 4 awk 编程

**awk** 是一个功能完整的文本处理语言，擅长按列处理结构化文本（日志、CSV、配置文件等）。awk 以字段为基本处理单位，天然适合表格数据。

### 4.1 工作原理与基本语法

基本调用形式：

```bash
awk 'BEGIN{ 初始化 } pattern{ action } END{ 收尾 }' file
```

处理流程如下：

```
 ┌─────────────┐
 │  BEGIN 块    │  ← 读取数据前执行一次（初始化变量、打印表头等）
 └──────┬──────┘
        ▼
 ┌─────────────┐
 │ 逐行读入数据  │ ──→ 按 FS 分割为 $1, $2, ..., $NF
 │   匹配 pattern│ ──→ 匹配成功则执行 action
 │   输出结果     │
 └──────┬──────┘
        │ 循环直到文件结束
        ▼
 ┌─────────────┐
 │   END 块     │  ← 所有行处理完后执行一次（汇总、统计等）
 └─────────────┘
```

**字段分割：**

```bash
# 默认按空白分割
echo "Alice 90 85" | awk '{print $1, $2}'
# 输出：Alice 90

# 用 -F 指定分隔符
awk -F: '{print $1, $3}' /etc/passwd

# 用 FS 变量（在 BEGIN 中设置）
awk 'BEGIN{FS=","} {print $1, $2}' data.csv
```

### 4.2 内置变量

| 变量 | 含义 | 默认值 |
|------|------|--------|
| `$0` | 当前整行内容 | — |
| `$1`, `$2`, ...`$NF` | 第 1、2、... 最后一个字段 | — |
| `NF` | 当前行的字段数（Number of Fields） | — |
| `NR` | 已读取的总行数（Number of Records） | — |
| `FNR` | 当前文件的行号（多文件时从 1 重新计数） | — |
| `FS` | 输入字段分隔符（Field Separator） | 空白 |
| `OFS` | 输出字段分隔符（Output Field Separator） | 空格 |
| `RS` | 输入记录分隔符（Record Separator） | `\n` |
| `ORS` | 输出记录分隔符（Output Record Separator） | `\n` |
| `FILENAME` | 当前处理的文件名 | — |
| `ARGC` / `ARGV` | 命令行参数个数和数组 | — |

```bash
# 打印每行的行号和字段数
awk '{print NR, NF, $0}' data.txt

# 多文件时区分文件行号
awk '{print FILENAME, FNR, $0}' file1.txt file2.txt

# 设置输出分隔符
awk -F: 'BEGIN{OFS="\t"} {print $1, $3, $7}' /etc/passwd
```

### 4.3 格式化输出

**`print` vs `printf`：**

- `print` 自动添加 ORS（默认换行），字段间用 OFS 分隔
- `printf` 不自动换行，支持精确的格式控制

| 格式符 | 含义 | 示例 |
|--------|------|------|
| `%s` | 字符串 | `printf "%s", name` |
| `%d` | 十进制整数 | `printf "%d", count` |
| `%f` | 浮点数 | `printf "%.2f", avg` |
| `%x` | 十六进制 | `printf "%x", num` |
| `%o` | 八进制 | `printf "%o", num` |
| `%e` | 科学计数法 | `printf "%e", big` |
| `%-Ns` | 左对齐，占 N 个字符宽度 | `printf "%-20s", name` |
| `%Nd` | 右对齐，占 N 个字符宽度 | `printf "%8d", count` |

```bash
# 格式化输出用户信息表
awk -F: 'BEGIN{printf "%-20s %-6s %s\n", "USER", "UID", "SHELL"}
         {printf "%-20s %-6d %s\n", $1, $3, $7}' /etc/passwd
```

### 4.4 模式匹配

awk 中的 pattern 决定哪些行被处理。

**正则匹配：**

```bash
# 整行匹配
awk '/ERROR/' app.log

# 指定字段匹配
awk -F: '$7 ~ /bash$/' /etc/passwd

# 字段不匹配
awk -F: '$7 !~ /nologin/' /etc/passwd
```

**关系运算：**

```bash
# UID 大于 1000 的用户
awk -F: '$3 > 1000 {print $1, $3}' /etc/passwd

# 第 3 列等于特定值
awk '$3 == "CRITICAL" {print}' events.log
```

**范围模式：**

```bash
# 打印 START 到 END 之间的行
awk '/START/,/END/' data.txt
```

**BEGIN 和 END：**

```bash
# 统计文件总行数
awk 'END{print NR}' file.txt

# 计算第 2 列的总和
awk '{sum += $2} END{print "Total:", sum}' sales.txt
```

### 4.5 流程控制

awk 支持完整的流程控制语句。

**if-else：**

```bash
awk -F: '{
    if ($3 == 0)
        print $1, "is root"
    else if ($3 < 1000)
        print $1, "is system user"
    else
        print $1, "is regular user"
}' /etc/passwd
```

**for 循环：**

```bash
# 打印 1 到 10 的平方
awk 'BEGIN{for(i=1; i<=10; i++) printf "%d^2 = %d\n", i, i*i}'
```

**while 循环：**

```bash
# 反转每行字段的顺序
awk '{
    i = NF
    while (i > 0) {
        printf "%s ", $i
        i--
    }
    printf "\n"
}' data.txt
```

**关联数组：**

awk 的数组是关联数组（类似哈希表），键可以是任意字符串。

```bash
# 统计单词频率
awk '{
    for (i=1; i<=NF; i++)
        count[$i]++
}
END {
    for (word in count)
        printf "%4d %s\n", count[word], word
}' article.txt | sort -rn | head -20

# 删除数组元素
awk 'BEGIN{
    a["x"]=1; a["y"]=2; a["z"]=3
    delete a["y"]
    for (k in a) print k, a[k]
}'
```

**数组检测：**

```bash
# 用 in 操作符检查键是否存在
awk '{if ($1 in seen) print "dup:", $0; else seen[$1]=1}' data.txt
```

### 4.6 内置函数

**字符串函数：**

| 函数 | 含义 | 示例 |
|------|------|------|
| `length(s)` | 字符串长度 | `length($0)` |
| `index(s, t)` | t 在 s 中首次出现的位置 | `index($0, "err")` |
| `substr(s, p, n)` | 子串，从位置 p 取 n 个字符 | `substr($0, 1, 10)` |
| `split(s, arr, sep)` | 拆分字符串到数组 | `split($0, a, ",")` |
| `sub(r, s, t)` | 替换第一个匹配 | `sub(/old/, "new", $0)` |
| `gsub(r, s, t)` | 替换所有匹配 | `gsub(/,/, "\t", $0)` |
| `match(s, r)` | 匹配正则，返回位置 | `match($0, /[0-9]+/)` |
| `tolower(s)` | 转小写 | `tolower($1)` |
| `toupper(s)` | 转大写 | `toupper($1)` |
| `sprintf(fmt, ...)` | 格式化字符串（不输出） | `s=sprintf("%05d",$1)` |

**数学函数：**

| 函数 | 含义 |
|------|------|
| `int(x)` | 取整（截断小数） |
| `sqrt(x)` | 平方根 |
| `sin(x)` / `cos(x)` | 三角函数 |
| `log(x)` / `exp(x)` | 自然对数 / 指数 |
| `rand()` | 返回 0 到 1 之间的随机数 |
| `srand(seed)` | 设置随机种子 |

**时间函数**（gawk）：

| 函数 | 含义 |
|------|------|
| `systime()` | 当前 Unix 时间戳 |
| `strftime(fmt, ts)` | 格式化时间戳 |
| `mktime(datespec)` | 日期字符串转时间戳 |

```bash
# 用 gawk 打印当前时间
gawk 'BEGIN{print strftime("%Y-%m-%d %H:%M:%S", systime())}'
```

### 4.7 实战示例

**统计日志中各 HTTP 状态码出现次数：**

```bash
# Nginx 日志格式：IP - - [time] "METHOD URI PROTO" STATUS SIZE ...
awk '{print $9}' access.log | sort | uniq -c | sort -rn | head -10

# 纯 awk 实现
awk '{status[$9]++} END{for(s in status) printf "%d\t%s\n", status[s], s}' access.log | sort -rn
```

**计算 CSV 文件某列的合计和平均值：**

```bash
# data.csv 格式：name,department,salary
awk -F, 'NR>1 {sum+=$3; count++}
END {printf "Total: %.2f\nAverage: %.2f\nCount: %d\n", sum, sum/count, count}' data.csv
```

```bash
awk -F: '$3 > 1000 {printf "%-20s UID=%-6d Shell=%s\n", $1, $3, $7}' /etc/passwd
```

**日志实时统计 QPS（每秒请求数）：**

```bash
# 假设日志每行含时间戳格式 [09/Mar/2026:14:30:05 +0800]
tail -f access.log | awk '{
    split($4, t, ":")

        }
```

## 5 find 文件查找

**find** 在目录树中按条件查找文件，并可对结果执行操作。它与 grep 互补——grep 搜索文件内容，find 搜索文件本身。

### 5.1 常用条件

| 条件 | 含义 | 示例 |
|------|------|------|
| `-name` | 按文件名匹配（区分大小写） | `-name "*.go"` |
| `-iname` | 按文件名匹配（忽略大小写） | `-iname "*.jpg"` |
| `-type` | 按类型：`f`文件 `d`目录 `l`链接 | `-type f` |
| `-size` | 按大小：`+100M` 大于，`-1k` 小于 | `-size +100M` |
| `-mtime` | 按修改时间（天）：`+7` 7天前，`-1` 1天内 | `-mtime +30` |
| `-atime` | 按访问时间（天） | `-atime -7` |
| `-ctime` | 按状态变更时间（天） | `-ctime +90` |
| `-mmin` | 按修改时间（分钟） | `-mmin -60` |
| `-user` | 按所属用户 | `-user root` |
| `-group` | 按所属组 | `-group docker` |
| `-perm` | 按权限：`644`精确，`-644`至少包含 | `-perm 755` |
| `-empty` | 空文件或空目录 | `-empty` |
| `-maxdepth` | 限制搜索深度 | `-maxdepth 2` |
| `-newer` | 比指定文件更新 | `-newer ref.txt` |

### 5.2 逻辑组合

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `-a` 或空格 | 逻辑与（默认） | `-name "*.log" -mtime +7` |
| `-o` | 逻辑或 | `-name "*.jpg" -o -name "*.png"` |
| `!` 或 `-not` | 逻辑非 | `! -name "*.tmp"` |
| `\( \)` | 分组 | `\( -name "*.go" -o -name "*.mod" \)` |

```bash
# 查找 Go 源码文件或测试文件，排除 vendor 目录
find . -path ./vendor -prune -o \( -name "*.go" -o -name "*.mod" \) -type f -print
```

### 5.3 动作执行

| 动作 | 含义 | 示例 |
|------|------|------|
| `-print` | 打印路径（默认） | `find . -name "*.log" -print` |
| `-exec cmd {} \;` | 对每个结果执行命令 | `-exec rm {} \;` |
| `-exec cmd {} +` | 批量传递结果（更高效） | `-exec chmod 644 {} +` |
| `-print0` | 以 `\0` 分隔结果 | `-print0` 配合 `xargs -0` |
| `-delete` | 直接删除匹配文件 | `-name "*.tmp" -delete` |

> ⚠️ **注意**：`-exec {} \;` 对每个文件单独启动一次进程，`-exec {} +` 将多个文件合并为一次调用，效率显著更高。对于含空格或特殊字符的文件名，使用 `-print0 | xargs -0` 确保安全。

```bash
# 批量模式 vs 逐个模式
find . -name "*.log" -exec wc -l {} +       # 一次调用 wc，高效
find . -name "*.log" -exec wc -l {} \;      # 每个文件调用一次 wc

# 安全处理特殊文件名
find . -name "*.bak" -print0 | xargs -0 rm -f
```

### 5.4 实战示例

**查找并删除 7 天前的日志：**

```bash
# 先确认将要删除的文件
find /var/log/app -name "*.log" -mtime +7 -type f -print

# 确认无误后删除
find /var/log/app -name "*.log" -mtime +7 -type f -delete
```

**查找大文件：**

```bash
# 查找大于 100MB 的文件，按大小排序
find / -type f -size +100M -exec ls -lh {} + 2>/dev/null | sort -k5 -h

# 查找当前目录下前 10 大文件
find . -type f -exec du -h {} + | sort -rh | head -10
```

**批量修改文件权限：**

```bash
# 目录权限设为 755，文件权限设为 644
find /var/www -type d -exec chmod 755 {} +
find /var/www -type f -exec chmod 644 {} +
```

**查找并处理最近修改的文件：**

```bash
# 查找 1 小时内修改过的 Go 文件
find . -name "*.go" -mmin -60 -type f

# 查找并统计代码行数
find ./src -name "*.go" -type f -exec wc -l {} + | tail -1
```

## 6 文本处理工具链

以下是文本处理中常与 grep、sed、awk 配合使用的工具。

### sort — 排序

按行排序文本。常用选项：`-n` 数值排序、`-r` 逆序、`-k N` 按第 N 列排序、`-t` 指定分隔符、`-u` 去重。

```bash
# 按第 3 列数值逆序排列，以逗号分隔
sort -t, -k3 -nr data.csv

# 按 IP 地址排序（版本排序）
sort -V ips.txt
```

### uniq — 去重

去除**相邻**的重复行。常用选项：`-c` 计数、`-d` 只显示重复行、`-u` 只显示唯一行。

```bash
# 统计词频（必须先排序）
sort words.txt | uniq -c | sort -rn | head -10
```

> ⚠️ **注意**：`uniq` 只去除相邻重复行，使用前必须 `sort`。如需直接去重且保持原序，用 `awk '!seen[$0]++'`。

### cut — 按列提取

从每行中提取特定字段或字符。常用选项：`-d` 分隔符、`-f` 字段范围、`-c` 字符范围。

```bash
# 提取 /etc/passwd 第 1 和第 7 列
cut -d: -f1,7 /etc/passwd

# 提取每行的前 20 个字符
cut -c1-20 data.txt
```

### tr — 字符转换

对标准输入进行字符级别的转换、删除或压缩。

```bash
# 小写转大写
echo "hello" | tr 'a-z' 'A-Z'

# 删除所有数字
echo "abc123def" | tr -d '0-9'

# 将连续空格压缩为一个
echo "a   b   c" | tr -s ' '

# 将换行转为空格（合并为一行）
tr '\n' ' ' < file.txt
```

### wc — 统计

统计行数、单词数、字符数。常用选项：`-l` 行数、`-w` 单词数、`-c` 字节数。

```bash
# 统计代码行数
find . -name "*.go" -exec cat {} + | wc -l

# 统计当前目录文件数量
ls | wc -l
```

### xargs — 参数传递

将标准输入转换为命令参数。核心选项：`-I{}` 指定占位符、`-n N` 每次传递 N 个参数、`-P N` 并行执行 N 个进程、`-0` 以 null 分隔输入。

```bash
# 查找并删除 .tmp 文件
find . -name "*.tmp" | xargs rm -f

# 并行压缩日志文件（4 个并行进程）
find /var/log -name "*.log" -mtime +7 | xargs -P 4 -I{} gzip {}

# 安全处理含空格的文件名
find . -name "*.bak" -print0 | xargs -0 rm -f
```

### paste — 合并列

将多个文件按列合并，或将单文件转为多列。

```bash
# 将两个文件按列合并（Tab 分隔）
paste names.txt scores.txt

# 将单列数据转为 3 列
paste -d, - - - < data.txt
```

### tee — 分流输出

将标准输入同时写入文件和标准输出（详见[第 5 章](../05-IO重定向与管道/IO重定向与管道.md)）。

```bash
# 保存命令输出同时查看
ps aux | tee processes.txt | grep nginx

# 追加模式
echo "new entry" | tee -a log.txt
```

### head / tail — 首尾提取

`head -n N` 取前 N 行，`tail -n N` 取后 N 行。`tail -f` 实时跟踪文件增长。

```bash
# 显示文件的前 20 行
head -n 20 large.log

# 实时监控日志（Ctrl+C 退出）
tail -f /var/log/syslog

# 跳过文件第一行（表头），显示剩余内容
tail -n +2 data.csv
```

## 7 经典管道组合

将多个工具通过管道串联，可以实现强大的数据处理流水线。以下是常见的实战组合：

| 场景 | 管道组合 | 说明 |
|------|----------|------|
| 统计 Top 10 访问 IP | `awk '{print $1}' access.log \| sort \| uniq -c \| sort -rn \| head -10` | 提取 IP → 排序 → 计数 → 逆序 → 取前 10 |
| 按扩展名统计文件数 | `find . -type f \| sed 's/.*\.//' \| sort \| uniq -c \| sort -rn` | 提取扩展名 → 统计 |
| 查找并杀掉进程 | `ps aux \| grep '[n]ginx' \| awk '{print $2}' \| xargs kill -9` | 过滤 → 提取 PID → 终止 |
| CSV 提取排序 | `tail -n +2 data.csv \| cut -d, -f1,3 \| sort -t, -k2 -nr \| head -20` | 跳过表头 → 取列 → 排序 → 取前 20 |
| 统计目录磁盘占用 | `du -sh */ \| sort -rh \| head -10` | 汇总大小 → 排序 → 取前 10 |
| 统计代码行数（按类型） | `find . -name '*.go' -type f \| xargs wc -l \| sort -rn \| head` | 查找文件 → 统计行数 → 排序 |
| 去重并保持原序 | `awk '!seen[$0]++' data.txt` | 利用 awk 关联数组实现 |
| 实时日志关键词监控 | `tail -f app.log \| grep --line-buffered "ERROR"` | 实时跟踪 → 过滤 |

**综合示例：日志分析流水线**

```bash
# 分析 Nginx 访问日志，生成一份完整报告
echo "=== Top 10 访问 IP ==="
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10

echo ""
echo "=== HTTP 状态码分布 ==="
awk '{print $9}' access.log | sort | uniq -c | sort -rn

echo ""
echo "=== 请求最多的 URL（Top 10）==="
awk '{print $7}' access.log | sort | uniq -c | sort -rn | head -10

echo ""
echo "=== 每小时请求量 ==="
awk -F'[/ :]' '{print $7":"$8}' access.log | sort | uniq -c
```

**综合示例：批量文本处理**

```bash
# 从 CSV 中提取销售额大于 1000 的记录，计算总额并格式化输出
awk -F, 'NR==1 {print; next}
$4 > 1000 {
    printf "%-15s %-10s %-8s %10.2f\n", $1, $2, $3, $4
    total += $4
    count++
}
END {
    printf "\n筛选 %d 条记录，总额：%.2f\n", count, total
}' sales.csv
```

## 8 小结

1. **正则表达式**是 grep、sed、awk 的共同基础。BRE 需要转义分组和量词，ERE 不需要；awk 原生使用 ERE。

2. **grep** 专注于搜索和过滤。`-E` 启用扩展正则，`-r` 递归搜索，`-A/B/C` 显示上下文，`--include` 限定文件类型。

3. **sed** 是流式编辑器，核心是 `s/old/new/flags` 替换命令。`-i` 原地修改，`-n` 配合 `p` 精确输出，地址定位支持行号、正则和范围。

4. **awk** 是完整的文本编程语言。`BEGIN/END` 块控制初始化和收尾，关联数组是统计分析的利器，`printf` 提供精确的格式控制。

5. **find** 按文件属性查找，`-exec {} +` 比 `\;` 高效，`-print0 | xargs -0` 安全处理特殊文件名。

6. **工具链协作**是 Unix 哲学的体现——每个工具做一件事，通过管道组合完成复杂任务。`sort | uniq -c` 统计频率，`xargs -P` 并行执行，`tee` 分流输出。

7. **实战原则**：先用 `grep` 过滤范围，再用 `awk`/`sed` 精细处理；对结构化数据优先用 `awk`，对简单替换优先用 `sed`。
