## 学习路径

```
基础篇                    进阶篇                    实战篇
┌──────────┐          ┌──────────┐          ┌──────────┐
│ 01 基础   │─────────→│ 05 I/O   │─────────→│ 07 错误  │
│ 02 引用   │          │ 06 文本   │          │ 08 实战  │
│ 03 流程   │          │          │          │          │
│ 04 函数   │          │          │          │          │
└──────────┘          └──────────┘          └──────────┘
```

- **基础篇（01-04）**：掌握 Shell 脚本的语言基础，足以编写日常自动化脚本
- **进阶篇（05-06）**：深入 I/O 机制和文本处理，驾驭复杂数据管道
- **实战篇（07-08）**：生产环境的防御性编程和完整脚本模式

## 适合谁

- 后端工程师、运维工程师、QA 工程师
- 需要编写自动化脚本的任何 IT 从业人员
- 有基本命令行经验，希望系统提升 Shell 编程能力

## 前置要求

- 熟悉基本的 Linux/macOS 终端操作
- 有任意一门编程语言的基础经验

## 每章结构

每章均包含：

- **概念讲解**：配合 ASCII 图和对比表格
- **代码示例**：每个知识点都有可直接运行的示例
- **实战场景**：来自真实运维和开发场景的案例
- **小结**：浓缩本章核心要点
- **动手练习**：3-4 个具体练习任务
