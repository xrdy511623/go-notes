# 1 明确你的搜索需求
搜索需求大致可以分为以下四个大类:
**信息资讯**
**知识技能**
**素材文件**
**工具软件**

在具体讲如何搜索之前，需要先明确以下四点:
## 1.1 为什么要搜索？

也就是你搜完后要干什么，刚好也基本上可以归纳为以下四个目的:
> 知道(know sth) 譬如你想知道杭州亚运会上中国得了多少块金牌，谁是Taylor Swift的最新男友等等。
> 学习(learn sth) 比如你想学习视频剪辑。
> 创作(create sth) 比如你要设计一个海报，写一篇文章等等。
> 完成任务(have sth done) 完成某个特定任务，譬如压缩文件、转换格式、抠除背景、生成二维码和翻译等等。

那么接下来要解决的问题就是:
> 要搜索啥？
> 去哪里搜？
> 怎么搜？

# 2 根据不同的搜索需求选择合适的搜索方法

下面重点围绕去哪搜和怎么搜做系统的讲解:

## 2.2 基础搜索语法

### 2.2.1 限定关键词
**就是在我们要搜的关键词左右两边加上英文的双引号**

譬如，我们想要搜索一个叫做易阳千喜的人，如果不限定关键词，就会出现2510万条结果，而且大部分都是另一个同音不同名
的明星易烊千玺的信息，我们很难从如此众多的搜索结果中找到我们想要的信息。如果我们限定关键词，那么查询结果会精确
很多，结果就只剩下不到900条，而且返回都是你想要的结果，都是易阳千喜相关的信息。


![before-limit-key-words.png](images%2Fbefore-limit-key-words.png)


![after-limit-key-words.png](images%2Fafter-limit-key-words.png)


**所以，限定关键词能大幅提高你的搜索效率**

有时你要搜一些报告数据，比如国际移民按性别统计，你直接输入关键词，搜索结果就太多了，2460万条，而且首页翻来翻去
也没找到与搜索关键词完全匹配的信息，但如果你加上双引号来限定这个关键词，就会发现搜索结果异常精确，返回的结果只剩下
不到10条。


![search-key-words.png](images%2Fsearch-key-words.png)


![search-limit-key-words.png](images%2Fsearch-limit-key-words.png)


点击第一条搜索结果进去，发现是一个pdf文档，那么怎么找到你想要的信息呢？很简单，ctrl(windows)或command(mac)+f输入你的关键字，
就能在这份pdf文档中迅速定位到你想要的信息，如下图所示，而且这份pdf文档也是可以下载的。


![search-info-in-file.png](images%2Fsearch-info-in-file.png)


![search-info-in-pdf.png](images%2Fsearch-info-in-pdf.png)


### 2.2.2 限定标题的搜索语法 intitle:xxx

比如说我们搜索iPhone15摄像头进灰，此时的返回的搜索结果高达2240万条，但是如果我们使用限定标题的搜索语法，在关键词
前加上intitle:(英文冒号)，返回的搜索结果就只剩下7条。这7条搜索结果的共同点是标题里都会出现iPhone15摄像头进灰的
关键词，这个就是限定标题，保证你的搜索结果标题里一定包含你想要的关键词信息。


![before-in-title.png](images%2Fbefore-in-title.png)


![after-in-title.png](images%2Fafter-in-title.png)


同时搜索语法是可以相互组合的，比如限定标题和限定关键词在这里组合使用，会进一步提高搜索精确度，最终只返回两条结果。
它确保你的搜索结果标题里一定包含你想要的关键词"iPhone15摄像头进灰"，而且这些关键词是限定的，必须完整的一起
(连续)出现，这就进一步提升了搜索的精确度。


![combination.png](images%2Fcombination.png)


### 2.2.3 限定标题出现多个关键词 allintitle:key1 key2 key3 ...

如果你想要搜索结果标题里不止出现一个关键词，可能有两个三个甚至更多，那此时可以使用allintitle语法来提高搜索效率。


![before-all-intitle.png](images%2Fbefore-all-intitle.png)


![after-all-intitle.png](images%2Fafter-all-intitle.png)


可以看到，没有使用allintitle语法时搜索结果高达1910万条，但使用该语法限定搜索结果标题必须出现这两个关键词后
搜索结果就只剩下82条，精准度大幅提升。

### 2.2.4 限定内容关键词语法 intext:"key1" "key2" "key3" ...

譬如我们想要搜索标题里有ELON MUSK关键词，同时内容里包含Spacex Starship Update的关键词，那我们就可以组合使用
intitle和intext语法提高搜索效率:


![intitle-and-intext.png](images%2Fintitle-and-intext.png)

谷歌都给你加了高亮显示，如此搜索准确度就很高了。

### 2.2.11 排除关键词 `-`

这可能是日常搜索中使用频率最高的技巧之一。在关键词前加上`-`(减号)可以排除包含该词的结果，
帮你快速过滤掉不想要的噪音。

**注意：减号前面要有空格，减号后面紧跟要排除的关键词，中间不能有空格。**

常用场景：
- `苹果 -水果 -食谱` → 排除水果相关结果，只搜Apple公司的信息
- `Go教程 -菜鸟教程` → 排除某个你不想看的网站的内容
- `Python爬虫 -培训 -广告` → 排除培训广告，只看技术内容
- `免费图片素材 -付费 -VIP` → 只找真正免费的素材

也可以和`site:`组合使用来排除某个网站：`Go并发编程 -site:csdn.net`

### 2.2.12 逻辑或搜索 `OR`

默认情况下，搜索引擎会查找同时包含所有关键词的结果。使用`OR`(必须大写)可以搜索包含任意一个
关键词的结果，相当于扩大搜索范围。

- `(教程 OR tutorial) Go语言` → 同时搜中文"教程"和英文"tutorial"
- `(Redis OR Memcached) 缓存方案` → 同时搜两种缓存中间件的方案
- `(kafka OR rocketmq OR pulsar) 消息队列对比` → 一次搜三种消息队列

`OR`在你不确定对方使用哪个词来描述同一件事时特别有用。

### 2.2.13 通配符 `*`

星号`*`可以作为通配符，代替一个或多个未知的词。当你记不全完整的短语或想探索不同表达时非常有用。

- `"最好的 * 编程语言"` → 搜索"最好的xxx编程语言"的各种说法
- `"Go * 最佳实践"` → 匹配"Go并发最佳实践""Go错误处理最佳实践"等
- `"how to * in Go"` → 搜索各种Go语言的how-to指南

### 2.2.14 限定时间范围 `before:` / `after:`

搜索技术相关内容时，时效性至关重要。2019年的Go教程和2025年的Go教程差别可能很大。
使用`before:`和`after:`可以限定搜索结果的时间范围（格式为YYYY-MM-DD）。

- `Go 1.24 新特性 after:2025-01-01` → 只搜2025年之后的内容
- `Docker最佳实践 after:2024-01-01 before:2025-12-31` → 限定在某个时间段内
- `React vs Vue after:2025-06-01` → 只看最近的对比文章

**这个语法对程序员来说尤其重要——技术文章过时很快，用时间范围能有效避免踩到过时信息的坑。**

### 2.2.15 查找相似网站 `related:`

当你找到一个好用的网站，想发现类似的网站时，可以使用`related:`语法。

- `related:github.com` → 找到类似GitHub的代码托管/开源平台
- `related:stackoverflow.com` → 找到类似Stack Overflow的技术问答社区
- `related:medium.com` → 找到类似Medium的博客平台

这个语法和前面提到的SimilarSites有异曲同工之妙，但不需要额外工具。

### 2.2.16 快速查看定义 `define:`

快速查看某个词或概念的定义，无需点击任何搜索结果。

- `define:idempotent` → 直接显示"幂等"的定义
- `define:CAP theorem` → 直接显示CAP定理的定义
- `define:eventual consistency` → 直接显示最终一致性的定义

对于快速确认某个专业术语的含义非常方便。

# 6 程序员搜索技巧

作为程序员，搜索是日常工作中最高频的技能之一。以下是一些专门面向开发者的搜索技巧。

## 6.1 搜索错误信息

遇到报错时，**直接复制错误信息加双引号搜索**是最高效的方法。但需要注意：
- 去掉错误信息中的文件路径、变量名等个性化部分，只保留通用的错误描述
- 保留错误码（如HTTP 429、Exit Code 137等）

例如：
- `"fatal error: concurrent map writes"` → Go并发写map的错误
- `"connection refused" MySQL Go` → Go连接MySQL被拒绝
- `"context deadline exceeded" gRPC` → gRPC调用超时

如果英文错误信息搜不到好结果，可以加上编程语言名称来缩小范围：
`"slice bounds out of range" Go`

## 6.2 搜索官方文档

用`site:`语法直接在官方文档中搜索，比通过搜索引擎搜到的第三方教程更准确：

- `site:go.dev context WithTimeout` → 在Go官方文档中搜context用法
- `site:redis.io CLUSTER` → 在Redis官方文档中搜集群相关内容
- `site:dev.mysql.com InnoDB lock` → 在MySQL官方文档中搜InnoDB锁机制
- `site:kafka.apache.org consumer group` → 在Kafka官方文档中搜消费者组

## 6.3 GitHub代码搜索

GitHub有自己的代码搜索语法，可以直接在搜索框中使用：

- `language:go "sync.Pool"` → 搜索Go项目中使用sync.Pool的真实代码
- `language:go "errgroup" stars:>100` → 搜索star数大于100的Go项目中errgroup的用法
- `filename:go.mod "go-redis"` → 搜索使用go-redis库的项目
- `path:Makefile "golangci-lint"` → 搜索Makefile中配置golangci-lint的项目

这比看教程更有价值——你能看到**生产级项目中真实的代码组织和用法**。

## 6.4 Stack Overflow高效搜索

Stack Overflow的内容质量高但数量庞大，用谷歌搜索语法能精确定位：

- `[go] goroutine leak site:stackoverflow.com` → 搜索Go标签下关于goroutine泄漏的问答
- `[mysql] deadlock InnoDB site:stackoverflow.com` → 搜索MySQL标签下关于InnoDB死锁的问答
- `is:answer score:10 [go] context` → 在Stack Overflow搜索页面中搜高分答案

## 6.5 搜索RFC和技术标准

当你需要了解某个协议或标准的权威定义时：

- `filetype:pdf RFC 7231` → 搜索HTTP/1.1语义的RFC文档
- `"RFC 9110" HTTP semantics` → 搜索最新的HTTP语义标准
- `site:ietf.org WebSocket protocol` → 在IETF官网搜索WebSocket协议

## 6.6 搜索性能基准测试

做技术选型时，性能数据是关键参考：

- `benchmark Go HTTP framework 2025 after:2025-01-01` → 搜索最新的Go HTTP框架性能对比
- `"TechEmpower" Go framework benchmark` → 搜索权威的Web框架性能排行
- `Redis vs Memcached benchmark filetype:pdf` → 搜索缓存中间件的性能对比报告

# 7 搜索语法速查表

| 语法 | 作用 | 示例 |
|------|------|------|
| `"关键词"` | 精确匹配，关键词必须完整连续出现 | `"Go语言并发模型"` |
| `intitle:xxx` | 标题必须包含关键词 | `intitle:性能优化` |
| `allintitle:x y` | 标题必须包含多个关键词 | `allintitle:Redis 持久化` |
| `intext:"xxx"` | 正文必须包含关键词 | `intext:"连接池调优"` |
| `inurl:xxx` | URL必须包含关键词 | `inurl:github` |
| `site:xxx.com` | 限定搜索结果来自某个网站 | `site:stackoverflow.com` |
| `filetype:pdf` | 限定搜索结果为某种文件格式 | `Go最佳实践 filetype:pdf` |
| `imagesize:WxH` | 限定图片尺寸 | `壁纸 imagesize:3840x2160` |
| `-关键词` | 排除包含该词的结果 | `苹果 -水果` |
| `OR` | 逻辑或，匹配任一关键词 | `(教程 OR tutorial) Go` |
| `*` | 通配符，代替未知的词 | `"最好的 * 编程语言"` |
| `before:YYYY-MM-DD` | 限定结果发布时间的上限 | `before:2026-01-01` |
| `after:YYYY-MM-DD` | 限定结果发布时间的下限 | `after:2025-06-01` |
| `related:xxx.com` | 查找与某网站相似的网站 | `related:github.com` |
| `define:xxx` | 快速查看某个词的定义 | `define:idempotent` |

**语法组合示例：**

- 搜索2025年之后知乎上关于Go性能优化的文章：`Go性能优化 site:zhihu.com after:2025-01-01`
- 搜索GitHub上star数高的Go连接池实现：`language:go "connection pool" stars:>50 site:github.com`
- 搜索排除广告的Redis教程PDF：`Redis教程 filetype:pdf -培训 -广告`
- 搜索标题包含MySQL且内容包含死锁的Stack Overflow问答：`intitle:MySQL intext:"deadlock" site:stackoverflow.com`
